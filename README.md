# 🖼️ Nautilus Image Converter

**Nautilus Image Converter** — Python-расширение для файлового менеджера [GNOME Files (Nautilus)](https://apps.gnome.org/Nautilus/), позволяющее быстро конвертировать изображения через контекстное меню.

Выделите одно или несколько изображений, нажмите правую кнопку мыши и выберите нужный формат. Конвертированные файлы будут сохранены рядом с оригиналами.

## ✨ Возможности

### Поддерживаемые форматы

Расширение позволяет конвертировать изображения в следующие форматы:

| Формат | Расширение | Особенности |
|---|---|---|
| PNG | `.png` | Сжатие без потерь, поддержка прозрачности |
| JPEG | `.jpg` | Сжатие с потерями, компактный размер |
| WEBP | `.webp` | Современный формат с эффективным сжатием |
| BMP | `.bmp` | Растровый формат без потерь |
| TIFF | `.tiff` | Формат для хранения и обработки изображений |

Поддерживаемые исходные форматы: PNG, JPG, JPEG, WEBP, BMP, TIFF и GIF. Возможность чтения конкретного формата зависит от поддержки Pillow.

### Основные функции

- **Контекстное меню Nautilus** — конвертация прямо из файлового менеджера.
- **Пакетная обработка** — возможность выбрать несколько изображений и конвертировать их за один раз.
- **Обработка прозрачности** — при конвертации изображения с прозрачностью в JPEG используется белый фон.
- **Обработка цветовых режимов** — преобразование несовместимых цветовых режимов для корректного сохранения.
- **Защита оригиналов** — исходные изображения не перезаписываются.
- **Автоматическое именование** — при совпадении имён создаются файлы с дополнительными суффиксами.
- **Логирование** — информация об операциях и ошибках записывается в лог-файл.

## 📦 Требования

- Linux с графическим окружением GNOME.
- GNOME Files (Nautilus).
- Python 3.
- Расширение `nautilus-python`.
- Библиотека Pillow.

## 🚀 Установка

### Fedora

Установите необходимые системные пакеты:

```bash
sudo dnf install nautilus nautilus-python python3-pillow libnotify
```

### Debian / Ubuntu

```bash
sudo apt update
sudo apt install nautilus python3-nautilus python3-gi python3-pil libnotify-bin
```

### Arch Linux

```bash
sudo pacman -S nautilus nautilus-python python-gobject python-pillow libnotify
```

> **Примечание:** названия пакетов могут отличаться в зависимости от дистрибутива и его версии. Для Fedora рекомендуется использовать системный пакет Pillow, а не устанавливать PyGObject и Nautilus API через `pip`.

### Установка расширения

1. Склонируйте репозиторий:

```bash
git clone <REPOSITORY_URL>
```

2. Перейдите в каталог проекта:

```bash
cd Extension_Convert_Image
```

3. Создайте каталог расширений Nautilus, если его ещё нет:

```bash
mkdir -p ~/.local/share/nautilus-python/extensions
```

4. Скопируйте файл расширения:

```bash
cp image_converter.py ~/.local/share/nautilus-python/extensions/
```

5. Перезапустите Nautilus:

```bash
nautilus -q
```

После следующего запуска Nautilus расширение должно загрузиться автоматически.

## 🖱️ Использование

1. Откройте Nautilus.
2. Выберите одно или несколько изображений.
3. Нажмите правую кнопку мыши.
4. Найдите пункт **«Конвертировать изображение»**.
5. Выберите целевой формат:
   - **PNG** — для изображений с прозрачностью и без потерь качества.
   - **JPEG** — для фотографий и уменьшения размера файлов.
   - **WEBP** — для эффективного сжатия.
   - **BMP** — для совместимости с программами, использующими BMP.
   - **TIFF** — для хранения изображений и дальнейшей обработки.

Готовые файлы появятся в той же папке, где находятся оригиналы.

## 📂 Именование файлов

Расширение не перезаписывает исходные изображения.

При конвертации создаётся новый файл с суффиксом `_converted`.

Если файл с таким именем уже существует, автоматически добавляется числовой суффикс:

```text
image.png
image_converted.webp
image_converted_2.webp
image_converted_3.webp
```

## ⚙️ Настройка

### Качество JPEG и WEBP

Для изменения качества сжатия найдите в `image_converter.py` параметр:

```python
"quality": 95
```

Значение задаётся в диапазоне от 1 до 100:

- `100` — максимальное качество, обычно больший размер файла.
- `95` — высокое качество.
- `80` — хороший баланс качества и размера.
- `60` — более сильное сжатие.

### Уведомления

Если в системе установлен `notify-send`, расширение может использовать системные уведомления для отображения результатов конвертации.

Для работы уведомлений в Fedora установите:

```bash
sudo dnf install libnotify
```

В Debian / Ubuntu:

```bash
sudo apt install libnotify-bin
```

## 🐛 Отладка

Если пункт меню не появился или конвертация не работает, проверьте следующие моменты:

1. Установлен ли `nautilus-python`.
2. Установлен ли Pillow.
3. Находится ли `image_converter.py` в правильном каталоге.
4. Был ли перезапущен Nautilus после установки.

### Просмотр журнала

Лог-файл находится в пользовательском каталоге:

```bash
~/.cache/nautilus-image-converter.log
```

Посмотреть журнал целиком:

```bash
cat ~/.cache/nautilus-image-converter.log
```

Следить за новыми записями в реальном времени:

```bash
tail -f ~/.cache/nautilus-image-converter.log
```

Если расширение не загружается, можно запустить Nautilus из терминала и посмотреть сообщения об ошибках:

```bash
nautilus -q
nautilus
```

## ⚠️ Ограничения

- Расширение предназначено для Linux и файлового менеджера Nautilus.
- В Windows и macOS оно не работает, поскольку использует API Nautilus и GNOME.
- Поддержка чтения и записи отдельных форматов зависит от возможностей Pillow.
- Некоторые метаданные изображения могут не сохраняться при конвертации. Результат зависит от исходного формата и параметров сохранения.
